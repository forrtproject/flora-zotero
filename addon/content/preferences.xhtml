Automatically check your library for replication studies at regular intervals Disable this option if you prefer to run all replication checks manually. Note: Auto-check runs in the background when Zotero is open. You can still manually check using the Tools menu. Libraries to include in scheduled checks Group libraries you can only read are skipped, because nothing can be added to them. Adding items to group libraries Applies to group libraries you can edit. For read-only libraries, the plugin always asks before copying to your personal library. Live counts from your Zotero library — updated automatically as items change Library: Library item Count Total library items — ↳ Original articles tracked (Has Been Replicated) (Has Been Reproduced) — ↳ Articles with replications (Has Been Replicated) — ↳ Articles identified as replications (Is Replication) — ↳ Articles with reproductions (Has Been Reproduced) — ↳ Articles identified as reproductions (Is Reproduction) — Open in FLoRA Atlas ↗ Open in FLoRA Atlas — opens the FLoRA Replication Atlas pre-loaded with the DOIs of every tracked item in the selected library: originals, replications and reproductions. The Atlas sorts them into its own Original / Replication tabs, so its counts reflect how FLoRA classifies each DOI rather than how your library tags it. The list is encrypted before it leaves Zotero, and the link stops working after 30 days. Anyone with the full link can see the list, so share it with care.
